# Contributing

Thank you for improving SDSD.

## Before Opening a Pull Request

1. Read `GUIA-SDSD.md` and `templates/specs/principles.md`.
2. For a methodology change, update the relevant guide and template together.
3. Run `python scripts/validate_docs.py`.
4. Run `pre-commit run --all-files` when working from a project generated by the templates.
5. Explain the user impact and validation performed in the pull request.

## Pull Requests

- Keep each pull request focused on one change.
- Do not include credentials, personal data, or generated artifacts.
- Update examples when changing the workflow they describe.
- Changes to principles, security guidance, or CI require explicit review.
