# Security Policy

## Scope

This repository contains development guidance and templates. Security reports may
concern the workflows, templates, examples, or documentation.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret.
Use GitHub's private vulnerability reporting for this repository, when enabled.
If it is unavailable, contact the repository maintainers privately through the
GitHub profile for `z4l1nux` and include reproduction steps, impact, and the
affected commit.

Please allow time for triage before public disclosure. Do not include real
credentials or personal data in a report.
