# SDSD Kit Specifications

This directory contains the constitution and maintenance state of the SDSD kit itself. A consumer project creates its own `specs/` by copying `templates/specs/`; these files describe this repository, not a product application.

- `mission.md`: purpose and audience of the kit.
- `principles.md`: constraints for maintaining the kit.
- `tech-stack.md`: validation tools and repository technology decisions.
- `roadmap.md`: planned kit improvements.
- `STATE.md`: current maintenance context.
- `adr/`: irreversible decisions affecting the kit contract.

The Portuguese source files remain the canonical filenames used by the repository. The English copies are provided for readers and must be kept semantically aligned.
