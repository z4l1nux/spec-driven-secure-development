# Mission

Make specification-driven, secure, and human-reviewed development more reproducible through a practical guide and copyable templates.

## What We Do

Provide a reusable SDSD guide and template kit for teams building software with AI agents, explicit security controls, and traceable decisions.

## Target Audience

Teams using AI agents to build or maintain software who need clear boundaries, traceability, and security gates.

## What Success Looks Like

A team can start a consumer project, create a specified feature, and validate its implementation using only this repository's guide and templates.
